# План: режим киоска (полноэкранный без рамок)

Согласовано с пользователем: включение только CLI-флагом `--kiosk`;
окно открывается через `showFullScreen()`; `F11` — переключение
полноэкранного и оконного режима в любой сессии; статус-бар
(версия + «Обновить») остаётся и в киоске; layout не адаптируется —
только геометрия окна; закрытие окна/Alt+F4 не блокируется;
авто-перезапуск после обновления убирается — вместо него модальный
диалог с просьбой перезапустить приложение.

## Факты

- Точка входа `src/PrintLabelMS/__main__.py`: `main()` разбирает
  argparse (позиционный `settings`, `--version`, подкоманды
  `update`/`rollback`), GUI запускает `_run_gui(settings_path)`.
- Окно создаётся в `on_loaded` по сигналу `StartupLoader.loaded` и
  показывается `window.show()`; ссылка удерживается в `refs`.
- `MainWindow` (`src/gui/MainWindow.py`) — `QMainWindow` с формой
  `mainwindow.ui`, размером по `sizeHint` (фиксированной геометрии
  нет); горячие клавиши создаются в коде окна
  (`QShortcut(QKeySequence("F9"), self)`), форма не содержит меню.
- Статус-бар создаётся в `MainWindow.__setup_update_ui`: `QLabel`
  с версией и `QPushButton("Обновить")`; кнопка блокируется до
  обнаружения новой версии (`__onUpdateAvailable`).
- После успешной установки `__onUpdateFinished` сейчас делает
  `QProcess.startDetached(sys.executable, ["-m", "PrintLabelMS"])` и
  `self.close()`, то есть перезапускает приложение без исходных
  аргументов (теряются `settings.json` и любые флаги).
- Конфиг (`Config`, схема v3) флага режима киоска не содержит и в
  этом плане не меняется: миграции и `settings_example.json` не
  затрагиваются.
- Лаунчеры аргументы не пробрасывают: `start.bat` вызывает
  `__main__.py settings.json` без `%*`, `.desktop` в `scripts/install.sh`
  — `Exec=${bin_dir}/${app}` без аргументов; киоск запускается вручную.
- `F11` не занят ни приложением, ни формой; `Esc` не перехватывается.
- Тесты GUI используют offscreen-QApplication; `tests/test_gui_lifetime.py`
  подменяет `gui.MainWindow` заглушкой `FakeMainWindow` с фиксированной
  сигнатурой конструктора и вызывает `_run_gui` с одним аргументом.

## Ограничения (принято)

- Версия приложения и схема конфига не меняются.
- Киоск — только стартовое состояние окна: `--kiosk` не блокирует
  закрытие, не скрывает статус-бар, не запрещает обновление и не
  делает окно always-on-top.
- `F11` доступен и без `--kiosk`; выход из полноэкранного режима по
  `F11` не меняет аргументы запуска — повторный запуск с `--kiosk`
  снова открывает окно во весь экран.
- Полноэкранное окно выводится на текущем/основном экране; выбор
  монитора не реализуется.
- `start.bat` и `.desktop` не меняются: киоск запускается командой
  `printlabelms --kiosk`.
- После установки обновления в работающем процессе остаётся старая
  версия до ручного перезапуска.

## Проверка

1) `pytest`; 2) `ruff check .`. Формы (`mainwindow.ui`) не менялись —
регенерация `gui/ui/` не требуется. Ручная проверка: запуск с
`--kiosk` и без него, переключение `F11` в обе стороны, печать и
калибровка по F9 в полноэкранном режиме.
