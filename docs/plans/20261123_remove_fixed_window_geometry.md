# План: убрать форсирование размера главного окна (доп. к TODO пункту 4)

Источник: прямое указание после реализации `ui_scale` — «нужно убрать
форсирование размера окна».

## Проблема

`src/gui/mainwindow.ui` задаёт MainWindow фиксированную начальную
геометрию 487×462 (`<property name="geometry">`). При `ui_scale != 1.0`
размер контента не совпадает с этой геометрией: при масштабе > 1 окно
растягивается минимум-сайзом layout'а, при < 1 остаётся 487×462 и
выглядит раздутым. Размер окна должен определяться контентом
(sizeHint), тогда он пропорционально масштабируется вместе с `ui_scale`.

## Файлы для модификации

- `src/gui/mainwindow.ui`: удалить `<property name="geometry">` у
  MainWindow (остальные свойства формы не менять).
- Регенерация `gui/ui/`: `python src/gui/__build__.py`; в
  `mainwindow_ui.py` исчезнет вызов `resize(487, 462)` — окно откроется
  в sizeHint layout'а.
- `docs/gui.md`: в разделе «Главное окно» пометить, что размер окна
  определяется контентом (без фиксированной геометрии).
