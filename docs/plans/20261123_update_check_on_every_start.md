# План: проверка новой версии при каждом старте (убрать 24-часовой кэш)

Источник: прямое указание после диагностики «кнопка Обновить не
загорается» сразу после релиза v0.4.0 — 24-часовой кэш проверки
удерживал тег v0.3.2 из более раннего запуска того же дня.
Согласовано: проверка при каждом старте, а не по таймеру.

## Проблема

`UpdateService.__check_worker` (`src/gui/update_service.py`) читает
кэш `~/.cache/printlabelms/update_check.json`; если с последней
проверки прошло меньше 24 ч, использует закэшированный тег без
опроса GitHub. Сразу после релиза пользователь не видит кнопку
«Обновить» до 24 часов.

## Решение

Убрать TTL и кеширование результата проверки: при каждом старте
`__check_worker` опрашивает `fetch_latest_release()`; если тег
новее текущей установки — эмитит `update_available`. Сетевые
ошибки по-прежнему глотаются молча (`except Exception: pass`).
Один запрос GitHub API на запуск приложения (лимит без
авторизации 60/ч с IP) — пренебрежимо для десктопа. Офлайн-запуск:
уведомления нет, как сейчас при любой сетевой ошибке.

## Файлы для модификации

- `src/gui/update_service.py`:
  - `__check_worker` — всегда `fetch_latest_release()` → тег →
    если новее текущей установки — эмит;
  - удалить `__read_update_cache`, запись кэша, импорты
    `json` и `datetime/timedelta`.
- `tests/test_update_service.py`:
  - существующие тесты остаются валидными (патчат
    `fetch_latest_release`, ассертов по TTL нет);
  - добавить тест: два последовательных `start_check()` →
    2 вызова fetch — фиксирует «проверка при каждом старте».
- `docs/gui.md`: «фоновая проверка новой версии раз в 24 ч» →
  «при каждом старте».
- `docs/architecture.md`: из абзаца про UpdateService убрать
  упоминание кэша `update_check.json`.
- `TODO.md`: удалить пункт 6 после реализации.

## Примечание

`updater.paths.cache_dir()` остаётся: её использует
`installer.py` как кэш загрузки wheel/SHA256SUMS — это другой
кэш, не связанный с проверкой обновлений.

## Побочные эффекты (приняты)

- Один запрос GitHub API на каждый запуск приложения.
- Офлайн-запуск: уведомления о новой версии нет.
