# GUI PrintLabelMS

## Назначение

Интерфейс приложения: сплэш-экран при загрузке данных, главное окно
(выбор товара/формата/шаблона и печать), диалоги фатальных ошибок
и уведомления об обновлениях.

## Компоненты

### Сплэш-экран

`src/gui/splash_screen.py`, `get_splash_screen()`. Показывается сразу
при запуске и маскирует загрузку данных МойСклада, которая идёт в
фоновом потоке (`StartupLoader`); логотип на непрозрачном белом фоне
и статус «Загружаем товары...». Фон обязан быть непрозрачным (белым):
на Linux без композитинга прозрачные области сплэша рендерятся чёрным.

### Главное окно

`src/gui/MainWindow.py`, `MainWindow`. Список товаров с фильтром,
выбор формата этикетки и шаблона; печать выполняется в фоновом
потоке, прогресс — `QProgressDialog`, операционные ошибки (печать)
показываются диалогом в окне. Окно создаётся по сигналу
`StartupLoader.loaded` (`src/PrintLabelMS/__main__.py`) и удерживается
владельцем до конца `app.exec()`: удаление окна (потеря ссылки)
завершает приложение. Форма окна — `mainwindow.ui`;
генерируемые файлы `gui/ui/` не коммитятся (регенерация —
`python src/gui/__build__.py`). Размер окна определяется контентом
(sizeHint layout'а), фиксированной геометрии в форме нет.
Коэффициент масштаба UI из конфига (`ui_scale`) применяется при
старте масштабированием шрифта приложения
(`src/gui/ui_scale.py`, `apply_ui_scale`); layout'ы растягивают
виджеты пропорционально.
Калибровочный эталон текущего формата печатается по `F9`: рамка
размера ценника с двумя диагоналями, всегда одна копия, без
товара/шаблона и запросов к МойСкладу. Печать идёт в фоновом потоке
с прогрессом; при активной печати шорткат показывает предупреждение.

### Фатальные ошибки

`src/gui/message_box.py`, `fatal_error(message)`. Критический диалог
при запуске: ошибки конфигурации, сети и МойСклада до открытия окна.

### Обновления

`src/gui/update_service.py`, `UpdateService`. Фоновая проверка новой
версии при каждом старте (флаг `check_updates`), update/rollback — в
отдельном потоке; общается с GUI через сигналы
(`update_available`, `progress_changed`, `finished`). Статус-бар
показывает текущую версию и кнопку «Обновить»; после успешного
обновления приложение перезапускается.
